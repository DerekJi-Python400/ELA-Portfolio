# Derek Ji — ELA Portfolio (Presentation Platform)

A **cartoon-style presentation website** anyone can open in a browser — built for classroom use on a **Promethean board**, projector, or laptop.

## For teachers (quick start)

1. **Open** `index.html` in Chrome, Edge, or Safari (double-click the file).
2. Click **Present** or **Fullscreen** at the top.
3. Use **arrow keys**, the big **Back / Next** buttons, or **tap** the left/right side of the screen.
4. Click any **slide thumbnail** at the bottom to jump to that slide.
5. Press **Esc** to exit fullscreen.

Click **?** in the toolbar for the same instructions inside the site.

## For students

Share the folder or upload to Google Drive / a simple website host. As long as the teacher can open `index.html` in a browser, it works — no login, no app install.

## Present controls

| Action | How |
|--------|-----|
| Next slide | → key, Space, **Next** button, tap right side |
| Previous slide | ← key, **Back** button, tap left side |
| Jump to slide | Click thumbnail (1, 2, or 3) |
| Fullscreen | **Fullscreen** button or **F** key |
| Present mode | **Present** button (hides toolbar, enlarges text) |

## Sharing with the class

- **USB / email:** Send the whole `ELA Portfolio Project` folder; open `index.html`.
- **Google Drive:** Upload folder → right-click `index.html` → Open with → Browser (or download and open locally).
